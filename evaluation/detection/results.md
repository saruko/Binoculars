# 検出率の評価結果

計画は [protocol.md](protocol.md) を参照してください。

**合成原稿での値で、実際の原稿での検出率ではありません。** 照合先にない文献は検出できず、この評価でも測っていません。設定は `dev` だけで決め、決めた後に `test` で1回確認しました。

## 全件の照合先での結果
照合先はPubMed抄録28,400,874件、PMC全文142,932件、手元のPDF 665件です。条件ごとの全数値は [results_dev_full.md](results_dev_full.md) と [results_test_full.md](results_test_full.md) にあります。

### 結論
- そのままの転用の検出率は、照合先が約8.7万件のときより下がりました。10語で約95%（8.7万件では約99%）、8語で76〜81%（85〜89%）です。15語以上はほぼ100%のままです。
- **転用のない文章でも値が大きく上がりました。** 地の文の一致率は2.7%から約11%に、人間の抄録では約15%になりました。無関係な文献にも同じ語句が見つかるためです。値の高さだけでは判断できません。
- 5語ごとの編集はほとんど検出できません（0.5〜5.0%）。8語ごと以上の編集と文字の加工は、ほぼ検出できます（98%以上）。
- 強い言い換えのうち、PubMed由来の文章は97〜98%を候補に挙げられました。日本語からの英訳は64〜86%で、devとtestの差が大きいままです。

| 条件 | 8.7万件（dev） | 全件（dev） | 全件（test） |
|---|---:|---:|---:|
| そのまま8語 pubmed / library | 89.0% / 86.5% | 78.5% / 79.5% | 76.0% / 80.5% |
| そのまま10語 pubmed / library | 99.5% / 99.0% | 95.0% / 96.5% | 95.5% / 96.0% |
| そのまま12語 pubmed / library | 100% / 100% | 98.5% / 98.0% | 98.0% / 98.0% |
| そのまま15語 pubmed / library | 100% / 100% | 99.5% / 100% | 99.5% / 100% |
| 同形文字（ギリシャ） | 98.5% | 98.5% | 99.0% |
| 強い言い換え、言い換え検索 pubmed | 97.9% | 97.9% | 96.8% |
| 強い言い換え、言い換え検索 library | 89.0% | 82.0% | 91.9% |
| 日本語からの英訳、言い換え検索 | 86.2% | 86.2% | 64.0% |
| 地の文の一致率（地の文のみ） | 2.7% | 11.1% | 11.3% |
| 地の文の一致率（人間の抄録） | 2.7% | 15.4% | 15.5% |
| 言い換え候補、1,000語あたり（地の文のみ） | 1.39 | 2.58 | 2.69 |

| 撤回の記録がない文献での誤検出 | 0/800 | 0/800 | 0/800 |

**強い言い換えのlibraryの低下は、ほぼ評価上のものです。** devの100件を調べると、6件はより近い文がPubMed側に見つかり、PDFの文が最上位から外れていました。うち少なくとも5件は同じ論文のPubMed記録で、評価ではこれも不正解に数えます。そのままの転用で「正しい出典」が93%前後で頭打ちになるのも、同じ理由の可能性があります（こちらは調べていません）。

### 候補の選び方（devのそのままの転用）
全件にすると、候補の順位付けで短い一致の出典が押し出され、10語の検出率が80%まで下がりました。指紋の頻度の上限を変えても改善せず、原因は順位付けでした。次の8通りを比べました。

| 区画の語数 / 区画ごとの件数 / 必ず残す指紋の頻度 | 8語 | 10語 | 12語 | 地の文 | 時間（1件） |
|---|---:|---:|---:|---:|---:|
| 100 / 20 / なし（変更前） | 55.5% | 80.0% | 91.5% | 8.4% | 約0.4秒 |
| 100 / 20 / 3文献まで | 72.5% | 90.5% | 96.0% | 9.1% | 約0.5秒 |
| 20 / 10 / 3文献まで | 75.0% | 93.5% | 96.5% | 9.9% | 約0.8秒 |
| 20 / 20 / 3文献まで | 79.0% | 94.0% | 98.0% | 10.8% | 約0.8秒 |
| **100 / 20 / 30文献まで（採用）** | **78.5%** | **95.0%** | **98.5%** | **11.1%** | **約1.0秒** |
| 20 / 10 / 30文献まで | 79.0% | 95.5% | 98.0% | 11.2% | 約1.2秒 |
| 20 / 20 / 30文献まで | 80.5% | 95.5% | 99.0% | 11.6% | 約1.3秒 |
| 100 / 20 / 100文献まで | 83.0% | 96.5% | 99.0% | 12.2% | 約2.4秒 |

値はpubmedの層です。差が誤差の範囲の設定の中で、変更が最も少ないものを選びました。

### 言い換えの索引（641万文）
眼科・アレルギー分野の抄録まで広げ、区画に分けた索引で128区画だけを調べます。`dev` の文で全件検索と比べると、約54倍速くなりました（毎秒2.7文から147文）。全件検索で閾値0.82以上に届いた文のうち、同じ文に届いた割合は、強い言い換えで99.5%、軽い推敲で100%、地の文で96.7%でした。

### 引用の重なりの基準
全件の引用の一覧（約3.96億件、1,047万文献）から3,000件を抜き取ると、これまでの基準（共通8件、重なり60%）では8.1%の論文にフラッグが出ました。共通10件以上、重なり80%以上、順序の一致70%以上に変えると、0.80〜0.90%になりました（3回の抜き取り）。題名がほぼ同じ組は10組のうち7組が残りました。**検出率は測っていません。**

## 照合先が約8.7万件のときの結果
以下の数値は、照合先がPubMed抄録86,443件と手元のPDF665件のときのものです。全数値は [results_dev.md](results_dev.md) と [results_test.md](results_test.md) にあります。

### 結論
- そのままの転用は10語以上でほぼ検出できます。8語では85〜89%です。
- 8語ごと以上の語の編集と、文の順序の入れ替えは、ほぼ検出できます。**5語ごとの編集はほとんど検出できません（0.5〜5.5%）。** 指紋（5語の連なり）が残らないためです。
- 文字の加工は、測った13種類すべてで検出率が98%以上になりました。全角、数学用英字、特殊な空白を除く10種類ではフラッグも出ます。
- LLMの強い言い換えは一致では検出できません（0%）が、言い換え検索で89〜98%を候補に挙げられます。
- 日本語からの英訳は、devとtestで差が大きく（86.2%と66.7%）、値は定まっていません。

処理時間は言い換え検索ありで合成原稿1件あたり約7〜13秒です（改良前は約2〜3秒）。

## 設定の根拠（devのみ）

### 候補文書の選び方
候補を指紋の重みの上位200件に絞っていたため、短い一致しかない文献が、別の箇所で定型句を多く共有する文献に押し出されていました。原稿を100語ごとに分け、それぞれの上位20件も候補に加えました。そのまま10語の検出率が98%から99.5%になり、地の文の一致率はほぼ変わりませんでした。

### 言い換え検索の閾値
BAAI/bge-m3の文単位の類似度に、SCDG（arXiv:2608.03859）の利得を組み合わせました。出典を読ませたときに、文の予測がどれだけ楽になるかを Qwen2.5-1.5B で測る値です。本物の言い換えと地の文を分ける力（AUC）は、類似度が0.874、利得が0.964でした。

| 設定 | 軽い推敲 pubmed / library | 強い言い換え pubmed / library | 地の文 1,000語あたり | 人間の抄録 1,000語あたり |
|---|---:|---:|---:|---:|
| 類似度0.85のみ | 100% / 93% | 92.6% / 89% | 2.55 | 2.82 |
| 類似度0.82 + 利得0.6（採用） | 100% / 93% | 97.9% / 90% | 1.42 | 2.62 |

この表は本来の出典との組だけを数えた試算で、上の結果表と少し異なります。利得の確認は英語だけで、日本語の文には使っていません。モデルが読み込めないときは類似度0.85に戻し、その旨を注記します。

### 英語と日本語の間の検索
文単位の検索で、英語の文から日本語の文を探すときは閾値を0.75にしました。devでは検出率89.2%、地の文の誤検出は1,000語あたり0.2でした（通常の閾値のままでは33.8%）。CL-OSAは Wikidata への依存があるため採用していません。

testでは66.7%で、devとの差は標本のばらつきだけとは言いにくい大きさです（95%信頼区間は 55.4〜76.3% と 75.7〜92.5%）。testを見て調整はしていません。原因は調べていないので、低いほうの値を想定してください。

### 文字の加工
正規化を見直しました。アルメニア文字は全文で置き換えます。ギリシャ文字などはラテン文字の単語の中に混ざった場合だけ置き換えるので、TGFα、IFNγ、αvβ3 はそのまま残ります。

### 表示と抽出の不一致（PDF）
本文のあるページから均等に最大4ページを選び、150 dpiで描画してOCRにかけ、抽出した文字列と語の一致率を比べます。一致率が0.6未満のページをフラッグにします。

手元のPDF 120件、468ページの一致率は、中央値0.985、最小0.674で、閾値未満はありませんでした。ToUnicodeだけを書き換えた合成PDFは検出できることを確認しました。**実際にこの手口を使ったPDFでは確認していません。** 選ばなかったページは見ません。

### 引用の重なり
参考文献のDOI、PMID、題名を照合先の文献の引用一覧と比べ、同じ文献との共通が8件以上で、共通の割合（少ないほうの参考文献数に対する割合）が60%以上のときにフラッグにします。登録済みの3,000件で試すと0.47%にフラッグが出て、上位はほとんどが同じ論文の別版か、とても近い論文でした。

**検出率は測っていません。** 正解付きのデータがないためです。参考文献を照合先の文献に結び付けられない場合は数えられません。

## 限界
- 5語ごとの編集は、言い換え検索を有効にした測定をしていません。
- 地の文はAIの文章で、実際の原稿とは異なります。
- 転用の加工は人工的で、実際の転用の分布を表しません。
- 不自然な語句のチェックの検出率は測っていません（[確認結果](../integrity/results.md)）。
- 表示と抽出の不一致と引用の重なりは合成原稿の条件に含まれず、上の検出率には反映されていません。
- 測定に使った合成原稿はTXTで、PDFとDOCXの抽出の誤りは含みません。
